참여할 사람에게는 안내를, 피할 사람에게는 경로를.

집회는 매일 서울 어딘가에서 신고됩니다. 오시요는 경찰청·서울시의 공식 신고 데이터 하나로, 참여하려는 시민과 피해가려는 시민 모두에게 각자 필요한 안내를 만듭니다.

로그인 없이, 개인 식별자 없이 — 처음부터 안 받는 것이 설계 원칙입니다.

참여하려는 사람

"이 집회, 오늘 몇 시부터야? 뭘 지키면서 참여해야 하지?"

피해가려는 사람

"오늘 퇴근길, 어디를 막고 있는 거야? 지도 앱은 왜 이걸 모르지?"

Problem

집회는 두 개의 얼굴을 가진 정보입니다

같은 신고서 한 장이 누구에게 보여주느냐에 따라 전혀 다른 정보가 되어야 합니다. 지금은 어느 쪽에도 정확히 맞춰진 서비스가 없습니다.

🙋

참여하려는 사람

"이 집회, 오늘 몇 시부터야? 뭘 지키면서 참여해야 하지?"

  • 언제·어디서 모이는지 공식 정보가 흩어져 있음
  • 준수사항(금지·의무)은 법조문 그대로라 읽기 어려움
  • 참여 의사를 밝히려면 로그인·개인정보가 필요한 경우가 많음
🚶

피해가려는 사람

"오늘 퇴근길, 어디를 막고 있는 거야? 지도 앱은 왜 이걸 모르지?"

  • 일반 지도 앱은 집회로 인한 통제를 실시간 반영하지 못함
  • 맞불 집회가 겹치면 통제 범위가 넓어지는데 알 방법이 없음
  • 행진은 계속 이동하는데 신고서엔 출발지만 적혀 있음

Why Now

기존 서비스는 이 틈을 메우지 못합니다

일반 지도 앱

교통 통제는 반영하지만 원인(집회)은 안 보여줌

우회는 알려줘도 "왜 막혔는지"는 모름

SNS·커뮤니티 정보

빠르지만 정확성 검증이 안 됨

출처·기준 시각이 없어 신뢰하기 어려움

오시요

경찰청·서울시 공식 신고 데이터 기반

모든 정보에 출처 + 기준 시각을 함께 표기

Solution

오시요 — 하나의 데이터, 두 개의 안내

경찰청·서울시가 이미 갖고 있는 집회 신고 데이터를, 두 종류의 시민에게 각자 필요한 형태로 다시 보여줍니다.

  • 오늘의 집회 검색·상세
  • 금지·의무·참고 준수사항 정리
  • 익명 참여 예정 집계
📋

  • 통제 회피 경로 + 지도앱 연결
