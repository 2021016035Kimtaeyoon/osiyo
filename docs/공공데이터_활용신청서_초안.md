# 공공데이터 제공신청서 초안 — 서울 집회·시위 신고 현황

data.go.kr 로그인 → 공공데이터 → 공공데이터 제공신청 → "공공데이터 제공신청서 작성하기"
에서 아래 내용을 그대로 복사해 채워 넣으시면 됩니다.

---

## 신청 데이터명

서울지방경찰청(서울특별시경찰청) 오늘의 집회 및 시위 신고 현황 (실시간/일단위 개방)

## 제공기관(소관기관)

경찰청 / 서울특별시경찰청

## 신청 구분

공공데이터 제공신청 (기계판독 가능한 형태 — API 또는 정기 업데이트 파일)

## 신청 사유 및 목적

시민에게 두 가지 정보를 제공하는 비영리·공익 목적의 웹 애플리케이션(오시요)을 개발 중입니다.
1) 집회 참여자에게는 준수사항·해산 시각 등 안내를,
2) 집회 참여 의사가 없는 시민에게는 통제 구간을 피한 우회 경로 안내를 제공합니다.

현재 서울경찰청 홈페이지의 "오늘의 집회/시위" 게시판(smpa.go.kr/user/nd54882.do)은
robots.txt로 자동 수집이 명시적으로 차단되어 있어, 동일한 정보를 공식적인 절차를 통해
합법적으로 제공받고자 신청합니다.

## 필요 항목 (상세)

- 집회명/주최자명
- 집회 장소(주소 또는 좌표)
- 집결 시작 시각 / 해산 예정 시각
- 신고 인원
- 행진 경로가 있는 경우 경로 상 주요 지점과 통과 예정 시각
- 진입 금지 구역, 통제 차로 등 통제 조건
- 소음 기준(dB) 등 신고서에 부기된 준수사항
- 신고 접수 시각 및 최종 수정 시각(데이터 기준 시각 표시용)

## 제공 희망 형식

- 1순위: OpenAPI(JSON), 10분~1시간 주기 갱신
- 2순위: 일 단위 정기 게시 파일(CSV/JSON) + 다운로드 URL 고정

## 활용 계획 요약

- 수집 주기: 10분 이상 간격, User-Agent 명시, 서버 부하 최소화
- 개인정보: 수집·저장하지 않음 (집회 자체의 공개 정보만 사용)
- 상업적 활용 없음, 오픈소스로 공개 예정
- 서비스 화면에 출처(경찰청/서울경찰청)와 데이터 기준 시각을 항상 함께 표시
